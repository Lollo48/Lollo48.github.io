HOW IT STARTED

From learning the basics to building complete systems.

My journey into game development started in 2022, when I enrolled in the Game Programming course at Event Horizon School in Milan.

C# and C++ initially forced me to rethink how I approached problems. That challenge is exactly what pulled me in. I became interested not only in making features work, but in understanding how to structure them so they remain understandable when a project grows.

Today my strongest interests are gameplay architecture, multiplayer networking and AI. I enjoy working from the architecture of a system through implementation, debugging, iteration and final integration.

HOW I WORK
