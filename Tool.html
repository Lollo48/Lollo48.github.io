01 / PURPOSE

Faster level placement

The tool was created to remove repetitive manual prefab placement from a level-design workflow.

A designer can choose a prefab, preview it directly in the scene, rotate it in fixed steps and place it while snapping to valid geometry.

02 / WORKFLOW

Editor-side features

PREVIEW

Real-time ghost

Shows the selected prefab under the cursor before committing placement.

SNAP

Surface snapping

Raycasts detect placement surfaces and align the object to the intended position.

ROTATION

90° increments

Quick rotation controls make common architectural placement predictable.

UI

Prefab selection

A lightweight editor interface lets the user swap the active prefab without leaving the placement flow.

03 / IMPLEMENTATION

Tool mechanics

  • Raycasting: Determines valid placement locations in the scene.
  • Preview lifecycle: Maintains a temporary representation without permanently modifying the scene.
  • Placement: Instantiates the selected prefab only after user confirmation.
  • Rotation state: Stores and applies deterministic orientation before placement.
