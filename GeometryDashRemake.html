01 / OVERVIEW

Rhythm, movement, timing

The remake reproduces the core idea of Geometry Dash: automatic forward movement, precise input timing and obstacle-driven level progression.

02 / MY WORK

Player forms & gameplay

FORMS

Multiple player pieces

Implemented cube, spaceship, robot, UFO, gear and spider forms with distinct movement behavior.

INPUT

Touch controls

Built the mobile input flow so forms remain responsive on touchscreen devices.

PORTALS

Movement modifiers

Implemented gravity, size, speed, teleport and other portal behaviors plus jump pads.

FEEDBACK

Events, VFX & sound

Connected player state changes, collisions and gameplay events to visual and audio feedback.

03 / CHALLENGES

Data-driven movement

The hardest part was keeping different movement models consistent while still allowing each form to feel unique.

  • Physics: Each player form needed its own movement characteristics without breaking collision consistency.
  • Speed: Movement speed had to react to level state and portals without producing jitter or unpredictable control.
  • ScriptableObjects: Form data was moved into assets so movement values and behavior could be tuned without rewriting code.
  • State separation: Each player form is represented through state-driven behavior, simplifying transitions between forms.
